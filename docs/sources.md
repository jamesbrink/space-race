# Sources

Everything this repo's numbers rest on, and what we know exists but have not read. Add to it
whenever you read something. A figure marked `documented` anywhere in the repo should trace to an
entry here.

Keys used in the hardware records: **primary** is a NASA or manufacturer document read directly;
**secondary** is anything else.

## Project Mercury

### Read

| Source | Where | Good for | Watch out for |
| --- | --- | --- | --- |
| *The Mercury-Redstone Project*, NASA TM X-53107, MSFC, 1964 | [PDF (Colorado State mirror)](https://www.engr.colostate.edu/~marchese/rockets15/projectmercury.pdf) | The booster: section lengths (Figure 4-1), weights, skin gauges, tank volumes, control limits. The pad: service structure, white room, mobile aerial tower, countdown (sections 7.2 to 7.5). Flight results (section 8, Table 8-1) | Figure 4-1 is not to scale. Section 8.3.1's prose has wrong dates and times; use its tables. Figure 7-6's "600 ft" is a distance, not a scale bar |
| *Postlaunch Report for Mercury-Redstone No. 3*, NASA Space Task Group, 16 June 1961 | [PDF](https://tothemoon.im-ldi.com/download_document?file_name=mercury_redstone_3_postlaunch_report.pdf&project=MERCURY) | **The authority for MR-3**: event times, trajectory, loads, capsule masses, centre of gravity and inertias, landing bag, hatch | |
| *Results of the First U.S. Manned Suborbital Space Flight*, NASA / NIH / NAS, 6 June 1961 | [NTRS 19720065957](https://ntrs.nasa.gov/api/citations/19720065957/downloads/19720065957.pdf) | Flight summary, spacecraft description, the beryllium shield | |
| Hammack and Heberlig, *The Mercury-Redstone Program*, ARS paper, October 1961 | [NTRS 20150018552](https://ntrs.nasa.gov/api/citations/20150018552/downloads/20150018552.pdf) | Shingle and pressure-vessel gauges, thruster ratings, cabin pressure, parachutes | |
| *Mercury Project Summary*, NASA SP-45, 1963 | [NTRS 19630012071](https://ntrs.nasa.gov/api/citations/19630012071/downloads/19630012071.pdf) | Table 3-III: nominal ratings of every solid motor. Flight durations | Nominal figures; the manufacturer's differ slightly |
| McDonnell Aircraft, *Project Mercury Familiarization Manual*, SEDR 104, rev. May 1962 | [PDF](https://sourceforge.net/projects/mscorbaddon/files/MercuryFamiliarizationManual20May1962.pdf/download) | Escape, jettison, posigrade and retro motors; the tower; antenna fairing; recovery compartment | The orbital-capsule edition: not No. 7's hatch or windows |
| Murphy, *Flight Test Aerodynamic Heating Data for the Afterbody of the Project Mercury Spacecraft*, NASA CR-649, 1967 | [NTRS 19670020040](https://ntrs.nasa.gov/api/citations/19670020040/downloads/19670020040.pdf) | The capsule's stated geometry: 74.5 in, 80 in, 20°, 32 by 20 in cylinder, canister, shingle gauges | Gives the canister as 24 in tapering to 20 in, which looks narrow against photographs |
| Swenson, Grimwood and Alexander, *This New Ocean*, NASA SP-4201, 1966 | [NASA History](https://history.nasa.gov/SP-4201/ch11-1.htm) | Hatch history, the 10 in ports, launch-morning times | Origin of three figures the telemetry does not support: 11.6 g, 5,180 mph, and a table entry of 15:28 |
| NASM object record A19620021000, *Capsule, Mercury, MR-3* | [airandspace.si.edu](https://airandspace.si.edu/collection-objects/capsule-mercury-mr-3/nasm_A19620021000) | Where the spacecraft is now; its size as displayed | Repeats 15:28 and 5,180 mph |
| NASA, *Project Mercury pressure suits* fact sheet (MA-8) | [PDF](https://www.nasa.gov/wp-content/uploads/static/history/40thmerc7/pressuresuits.pdf) | The suit, described 18 months after MR-3 | Later configuration than Shepard flew |
| collectSPACE, *Shepard's Freedom 7 spacesuit* | [collectspace.com](https://www.collectspace.com/news/news-050521a-shepard-freedom-7-spacesuit-60th-smithsonian.html) | The flown suit as conserved | |
| Wikipedia: Mercury-Redstone 3, Mercury-Redstone Launch Vehicle, Navy Mark IV, Cape Canaveral Launch Complex 5 and 6 | [MR-3](https://en.wikipedia.org/wiki/Mercury-Redstone_3) and siblings | Pad coordinates, launch counts, the suit, pointers to primaries | MR-3's timeline table is unreliable (separation at 02:24, apogee at 05:00) |
| Stephens, NASA TM X-493, 1961 | [NTRS 19650003098](https://ntrs.nasa.gov/api/citations/19650003098/downloads/19650003098.pdf) | Big Joe boilerplate only | Not the production spacecraft |
| McCutcheon, *The Redstone Engine*, AEHS | [enginehistory.org](https://enginehistory.org/Museums/USSRC/USSRC_Redstone.shtml) | A-7 lineage | Its A-7 performance line conflicts with TM X-53107 |

# Sources

Everything this repo's numbers rest on, and what we know exists but have not read. Add to it
whenever you read something. A figure marked `documented` anywhere in the repo should trace to an
entry here.

Keys used in the hardware records: **primary** is a NASA or manufacturer document read directly;
**secondary** is anything else.
